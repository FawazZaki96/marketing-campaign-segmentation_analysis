# 📂 Data Overview

## 📌 Dataset Description

This dataset contains customer-level information used to analyze marketing campaign performance.

---

## 📊 Key Fields

* **Income** → Customer earning level
* **Year_Birth** → Used to calculate age
* **Total Spending (engineered)** → Total purchase value
* **Response** → Campaign response (1 = accepted, 0 = not accepted)

---

## ⚙️ Data Preparation

The dataset was cleaned and transformed using Excel:

* Handled missing values (Income)
* Created new features:

  * Age
  * Total Spending
  * Income Group
  * Spending Group
* Converted response to numeric format
