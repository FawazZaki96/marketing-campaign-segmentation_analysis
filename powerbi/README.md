# 📊 Power BI Dashboard

## 📌 Purpose

This dashboard visualizes customer segmentation and campaign performance to support marketing decisions.

---

## 📊 Key Visuals

* KPI Cards (Customers, Response Rate, Spending)
* Scatter Plot (Segment Performance)
* Response Rate by Spending Group
* Customer Distribution by Segment
* Total Spending Analysis

---

## 🧠 Key Feature

The dashboard highlights:

* Trade-offs between **customer size, response rate, and revenue**
* Identification of **high-value target segments**

## 🚀 Outcome

Provides a **decision-driven view** to optimize marketing targeting and improve ROI.
